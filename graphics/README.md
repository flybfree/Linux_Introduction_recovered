## Conventions

- Add a `lesson-NN/` folder as each chapter's illustrations are developed.
- Name figures `NN-short-description.png` (or the appropriate image format). Keep these names stable once linked from a chapter.
- Keep each lesson's figure list, captions, alt text, placement, and review status in its `README.md`.
- Preserve generation prompts or editable source files beside the image. Record the production method and distinguish generated illustrations from captured screenshots.
- Embed figures in the source chapter with a relative path, descriptive alt text, and a visible caption.
- Save revisions as new versions until a replacement is deliberately selected. Mark planned figures clearly; do not link to nonexistent assets.

Current illustrations are working drafts for instructional review.
